Discovery is the only phase of an integration project routinely estimated at zero. It has no tickets, produces no software, and is therefore invisible to the instruments the programme uses to see itself.

## Why zero is the default

The work is conversational, so it does not decompose into tasks, so it does not appear in the plan. It still takes the time it takes.

## Estimate by interface, not by phase

Count interfaces, count the number of parties who must agree per interface, and allow half a day per pair. The number you get is uncomfortable and roughly correct.
