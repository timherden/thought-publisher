Put whitepaper PDFs here, named after the slug of the matching file in `content/papers/`.

    content/papers/readiness.md   →   public/pdfs/readiness.pdf

The whitepaper page links straight to that path with a `download` attribute. A missing file
gives a 404 on click and nothing else breaks, so it is safe to publish the page first and
add the PDF later.
